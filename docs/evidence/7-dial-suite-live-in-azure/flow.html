PilotGate DIAL suite, live in Azure Container Apps

Captured 2026-11-27 from real requests to the deployment, which was removed afterwards with deploy.ps1 -Destroy. DIAL keys are redacted; all data is synthetic.

DIAL Core with Redis, DIAL Guard, ClaimsAssist and a mock model, deployed by infra/dial/deploy.ps1 into one Container Apps environment next to the existing Azure OpenAI account. Only DIAL Core is public.

How a request flows

  1. Core sends the request through the guard (request side: quarantine, attachment check).
  2. The guard calls Core again with the same per-request key for the next hop, and checks every streamed chunk on the way back.
  3. Core routes to the deployment's application: ClaimsAssist, or the mock model for mock-echo. ClaimsAssist asks Core who the caller is and never trusts request headers.
